SECTION 7: FAT TAIL MECHANISM CLOSEUP (inside thigh)
================================================================================

         TOP OF THIGH
    +----------------------------------------------+
    |   +====================+                      |
    |   |    BLDC MOTOR      |  <- brushless motor  |
    |   |   (brushless)      |     spins flywheel   |
    |   |   ~24V, high RPM   |     target: 9000 rpm |
    |   +=========|==========+     driven by ESC    |
    |             | motor shaft                     |
    |     +-------+---------+                       |
    |    /                   \                      |  FLYWHEEL:
    |   |   +--------------+  |                     |  16 lb steel disc
    |   |   | ### STEEL ### |  |  <--16lb flywheel  |  diameter ~15cm
    |   |   | ###  DISC ### |  |     5" diameter    |  spins @ 9000 rpm
    |   |   | ############  |  |     STORES ENERGY  |
    |    \                   /                      |
    |     +-------+---------+                       |
    |     +-------+---------+                       |  CLUTCH:
    |     |   SOLENOID      |  <- 12V pull type     |  Normally OPEN.
    |     |    CLUTCH       |     fires in < 5ms    |  Fire solenoid ->
    |     |  MOSFET driven  |                       |  pad clamps disc
    |     +-------+---------+                       |  to output spool
    |      +------+------+                          |
    |      |  (cord) SPOOL|  =====+                 |  OUTPUT DRUM:
    |      +--------------+       |                 |  Dyneema cord wound
    +------------------------------|-----------------+  on drum. When clutch
                                   |                    engages, drum spins,
                            Dyneema cord                yanks cord HARD.
                                   |
               KNEE  -----(pulley)-+-------> cord guide
                                   |
               ANKLE ---(pulley)---+-------> cord guide
                                   |
               FOOT  ==============+  <- cord anchors to foot toe

  HOW IT WORKS:
   1. BLDC motor spins 16lb flywheel to 9000 rpm (stores kinetic energy).
   2. Solenoid clutch is OPEN -- flywheel free-spins, foot relaxed.
   3. Arduino fires solenoid -> clutch CLAMPS flywheel to spool.
   4. Spinning energy transfers to spool -> cord YANKS foot forward FAST.
   5. Explosive pull = jump / running stride (fires in ~40 milliseconds).
   6. Release clutch, motor re-spins flywheel for next step.

  RUNNING MODE: flywheel stays spinning continuously, solenoid fires
  alternating left/right with each step -> explosive sprint gait.

  !! WARNING: 9000 RPM steel disc is EXTREMELY DANGEROUS.
     An adult MUST supervise. Use a steel containment shield
     bolted around flywheel inside the thigh. Never run uncontained.

================================================================================
SAFETY RULES (read with an adult before building)
================================================================================

  1. FLYWHEEL: The 16lb steel disc spinning at 9000rpm stores massive
     energy. ALWAYS build a steel containment shield bolted around it
     inside the thigh panel. NEVER run the flywheel uncontained.
     An adult MUST be present when testing.

  2. LIPO BATTERY: Can catch fire if shorted, overcharged, or punctured.
     - Always use the correct balance charger
     - Charge inside a fireproof LiPo charging bag
     - Never leave charging unattended
     - Store in a cool dry place away from flammable materials

  3. FUSES: Every rail MUST have its own fuse. Do not skip fuses.
     A short without a fuse = fire.

  4. COMMON GROUND: Every component's ground wire must connect to the
     same ground rail. If grounds are not connected, signals will not
     work and components may be damaged.

  5. HIGH TORQUE SERVOS: 150KG servos can crush fingers and break bones.
     Never put hands near joints when power is on.

  6. FIRST BUILD: Build one arm first and test it fully before building
     the full robot. Go section by section.
