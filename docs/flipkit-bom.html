WHY PI ZERO 2W.
Runs full Raspberry Pi OS — Python scripts, SSH over WiFi, a real web browser. BadUSB works via USB gadget mode (one line in config.txt). Camera works with libcamera out of the box. PiSugar 3 clips onto the bottom — no wiring, charges via USB-C, reports battery over I2C.
