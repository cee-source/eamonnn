STAGE 02
Flash + Boot Pi OS
While parts ship, set up the software. Flash microSD, enable SSH over WiFi, and confirm the Pi boots.
Download Raspberry Pi Imager on your laptop
Flash "Raspberry Pi OS Lite (64-bit)" to microSD
In Imager settings: set hostname, WiFi SSID/password, enable SSH
Insert SD, power Pi via USB — wait 90 seconds
SSH in: ssh pi@flipkit.local
Run sudo apt update && sudo apt upgrade -y
While parts ship — this stage can be done on any Pi or even before hardware arrives.
⏱ DAY 1–7 (while shipping)
3
STAGE 03
Attach PiSugar + Camera
PiSugar 3 clips onto the bottom of the Pi Zero — no soldering. Camera plugs in via CSI ribbon.
Clip PiSugar 3 onto Pi Zero pogo pins (no wires)
Connect 15-pin CSI ribbon cable (Pi Zero uses narrow end)
Enable camera: sudo raspi-config → Interface Options → Camera
Test: libcamera-still -o test.jpg
Test PiSugar: pip install pisugar-server → check battery %
⏱ 30 MIN · no soldering
4
STAGE 04
Wire Display + Touch
Connect the ILI9341 TFT to the Pi GPIO header with jumper wires, then install the display driver.
Wire 14 pins: VCC→3.3V, GND, MOSI→GPIO10, SCK→GPIO11, MISO→GPIO9, CS→GPIO8, DC→GPIO25, RST→GPIO24, CS_T→GPIO7, IRQ→GPIO17, LED→3.3V
Install fbcp-ili9341: git clone https://github.com/juj/fbcp-ili9341
Build + run driver (cmake with -DILI9341=ON -DSPI_BUS_CLOCK_DIVISOR=6)
See Pi desktop on the tiny screen ✓
Calibrate touch with xinput-calibrator
⏱ 1–2 HRS
5
STAGE 05
Wire Radios + Mic
Add the radio modules and microphone one at a time, testing each before moving to the next.
Wire INMP441 mic → GPIO 18/19/20, enable I2S in raspi-config, test with arecord
Wire PN532 NFC → I2C (GPIO 2/3), install nfcpy, scan a card
Wire RDM6300 RFID → GPIO 15 (UART), test with pyserial
Wire CC1101 → SPI (CS: GPIO 5), install python-cc1101, capture 433MHz
Wire IR LED → GPIO 12, TSOP → GPIO 23, install lirc, record + replay a remote
Wire 8 buttons → GPIO 4,14,22,27,16,26,13,21 with 10kΩ pull-ups
⏱ 2–4 HRS
6
STAGE 06
Design + Order GPIO HAT
Replace the jumper wire rats-nest with a clean custom PCB HAT that connects everything neatly.
Open EasyEDA → new project "FlipKit HAT"
Place Pi Zero 2W 40-pin header footprint
Add headers for display (J1 14-pin), mic, each radio module
Route traces — keep SPI lines short, add 100nF bypass caps
Export Gerber → upload to JLCPCB → order 5 boards (~$8)
Wait ~7 days for boards to arrive
Optional but recommended — jumper wires work fine for testing. HAT makes it portable and reliable.
⏱ 2–3 HRS DESIGN · 7 DAYS SHIP
7
STAGE 07
FlipKit Software + Case
Install the FlipKit UI, enable BadUSB, print the case, and you have a working device.
Clone flipkit repo → install Python dependencies
Enable BadUSB: add dtoverlay=dwc2 + modules-load=dwc2,g_hid to config.txt
Set FlipKit UI to launch on boot (systemd service)
Download Pi Zero 2W case from Printables.com (or design custom)
3D print case — PLA, 0.2mm layer height
Assemble: Pi + PiSugar + HAT + display into case ✓
⏱ 2–4 HRS · DONE
