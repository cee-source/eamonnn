# Eamonn's Arduino Adventure

Hi Eamonn! This is your step-by-step guide to building real electronics gadgets with your Arduino.

By the end of these lessons you'll be able to:
- Write code that controls the real world
- Build circuits on a breadboard
- Make lights, sounds, and moving parts work together

## How to Use These Lessons

1. Start at **Lesson 00** — don't skip it!
2. Go in order — each lesson builds on the last
3. **Type the code yourself** — don't copy and paste. Typing it helps you remember it
4. Try the **challenges** at the end of each lesson
5. If something doesn't work, check the **troubleshooting** section

## Safety Rules

- Always **unplug the USB cable** before changing your wiring
- Never connect more than **5 volts** to your Arduino pins
- Keep drinks **away** from your electronics
- If anything gets very hot or smells funny, **unplug it immediately**
